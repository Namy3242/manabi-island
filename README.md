# 🏝️ まなびアイランド

ブラウザで遊べる、子供向け知育アプリです。インストール不要で、スマホ・タブレット・パソコンのブラウザでそのまま遊べます。

## 遊び方

1. トップ画面でコースを選びます（選んだコースは端末に保存され、次回も引き継がれます）。
2. ゲームカードをタップすると、10問1セットのゲームが始まります。
3. 4つのボタンから答えを選びます。正解するとスター⭐が1つ貯まります。
4. 間違えても大丈夫。ヒントが出るので、もう一度挑戦できます（スターが減ることはありません）。
5. 10問終わると結果画面が出ます。「もういちど」で同じゲームを再挑戦、「トップへ」でゲーム選択に戻ります。

右上のスピーカーボタンで効果音のオン／オフを切り替えられます。スターの合計とコース選択は、この端末のブラウザ（localStorage）にだけ保存されます。

## ゲーム内容

| ゲーム | ようちえん（年中・年長） | しょうがくせい（小1〜小3） |
|---|---|---|
| かず・さんすう | 絵の数を数える（1〜20）、絵ヒント付きの簡単な足し算（合計10まで） | 足し算・引き算（2桁まで）、かけ算九九 |
| もじ | 絵を見て合うひらがなを選ぶ／ひらがなを見て合う絵を選ぶ | カタカナの読み、小1〜小3で習う漢字の読み |
| とけい | アナログ時計を読む（○時ちょうど・○時30分） | アナログ時計を読む（5分刻み） |

## 対象年齢

- ようちえんコース：年中〜年長（4〜6歳くらい）
- しょうがくせいコース：小学1〜3年生（6〜9歳くらい）

大人がそばで声をかけてあげると、より楽しく学べます。

## ローカルでの開き方

### 方法1：ファイルをそのまま開く

`index.html` をブラウザで開くだけで遊べます（ダブルクリック、またはブラウザにドラッグ＆ドロップ）。

### 方法2：簡易HTTPサーバーで開く

```bash
cd manabi-island
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。同じWi-Fi内のスマホやタブレットからは、`http://（パソコンのIPアドレス）:8000` でも開けます。

## GitHub Pagesで公開する手順

1. このフォルダの中身（`index.html` / `style.css` / `app.js` / `README.md`）を GitHub リポジトリのルートに push します。
2. GitHub のリポジトリページで **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch に **main**、フォルダに **/ (root)** を指定して **Save** します。
4. 数分待つと `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます。Pages の画面に表示される URL を開いて確認してください。

## プライバシーについて

- 子供の名前・写真などの個人情報は一切扱いません。
- 通信は行わず、進捗（スター数・コース）は端末の localStorage にのみ保存されます。
- 外部フォント・画像・ライブラリは使っていないため、オフラインでも（初回読み込み後）動作します。

## 技術構成

- 素の HTML / CSS / JavaScript（ビルド不要、フレームワークなし）
- 時計は SVG で描画、効果音は Web Audio API で生成（音声ファイルなし）
- 絵は絵文字と CSS で表現
